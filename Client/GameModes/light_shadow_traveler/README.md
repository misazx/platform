# 光影旅者 (Light Shadow Traveler)

> 治愈系 2D 横版平台跳跃游戏

---

## 快速开始

### 核心玩法
在遗忘之地的世界中，光与影是平衡世界的关键力量。主角小影在光与影之间穿梭，收集记忆碎片，恢复世界平衡。

### 核心机制
- **光影形态切换** - 光形态与影形态各有特色能力
- **双平台跳跃** - 光平台和影平台交替出现
- **光影形态感应** - 与环境互动解谜
- **记忆碎片收集** - 解锁故事与皮肤

---

## 如何游玩

### 启动方式

1. 在 Godot 编辑器中打开项目
2. 运行主场景 `GameScene.tscn`
3. 使用键盘控制：
   - A/D 或 左/右 方向键移动
   - 空格/W 或上方向键跳跃
   - Shift/Tab 切换光/影形态

### 游戏特色

- 🎨 光与影切换的核心玩法
- 🎭 光形态冲刺，影形态滑翔
- 🧩 光影互动解谜
- 📱 多平台支持
